Deep TDOA: GCC-PHAT, Sub-Sample Fitting, & Hyperbolic Solvers

In Lesson 11, we saw the high-level geometry of Time Difference of Arrival (TDOA). But when you sit down to implement a multi-receiver correlation system in code, you immediately collide with two brutal physical realities:

  1. Multipath Reflection Smear: In urban and terrestrial RF channels, radio waves bounce off hills, buildings, and ground plane conductors. Standard cross-correlation yields a wide, noisy blob with multiple false peaks.
  2. The 2.0 MSPS Coarseness Limit: At a 2.0 MSPS sample rate, one discrete sample interval is $T_s = 0.5\ \mu\text{s}$. Because light travels 300 meters per microsecond, a single integer sample error equals 150 meters of positional uncertainty!

Let's examine how professional electronic surveillance (SIGINT) and multilateration systems solve these two problems.

1. GCC-PHAT: The Mathematics of Phase Whitening

In naive cross-correlation, we compute the cross-power spectral density:

$$G_{xy}(f) = X(f) \cdot Y^*(f)$$ $$R_{xy}(\tau) = \mathcal{F}^{-1} \big\{ G_{xy}(f) \big\}$$

The fatal flaw is that frequency bands with high power dominate the summation, while multipath reflections produce constructive and destructive interference ripples across the spectrum.

The Phase Transform (PHAT)

In 1976, Knapp and Carter introduced the Generalized Cross-Correlation with Phase Transform (GCC-PHAT). It applies an adaptive whitening filter that normalizes the magnitude of every frequency bin to unity:

$$\psi_{\text{PHAT}}(f) = \frac{1}{|G_{xy}(f)| + \epsilon}$$

The GCC-PHAT correlation function is defined as:

$$R_{xy}^{\text{PHAT}}(\tau) = \mathcal{F}^{-1} \left\{ \frac{X(f) \cdot Y^*(f)}{|X(f) \cdot Y^*(f)| + \epsilon} \right\}$$
The Dirac Delta Miracle

Look at what remains inside the inverse Fourier transform:

$$\frac{X(f) \cdot Y^*(f)}{|X(f) \cdot Y^*(f)|} = e^{j \angle G_{xy}(f)} = e^{-j 2\pi f \Delta t}$$

Every single frequency bin has had its magnitude stripped away to exactly 1.0, preserving strictly the phase slope across frequency!

The inverse Fourier transform of a pure linear phase exponential with flat unity magnitude is:

$$\mathcal{F}^{-1} \big\{ e^{-j 2\pi f \Delta t} \big\} = \mathbf{\delta(t - \Delta t)}$$

A razor-sharp Dirac delta spike! The multipath smearing and signal amplitude variations collapse into an ultra-narrow impulse right at the true time delay $\Delta t$.

2. Sub-Sample Resolution: The Parabolic Extremum Interpolator

After computing GCC-PHAT, we find the highest discrete peak at integer array index $k_{\text{peak}}$. Because $T_s = 0.5\ \mu\text{s} \equiv 150\text{ meters}$, picking only the nearest integer index yields unacceptable $\pm 150\text{m}$ quantization steps.

However, the underlying physical electromagnetic wave is continuous. The true analog peak falls somewhere at a fractional offset $\delta \in (-0.5, +0.5)$ around $k_{\text{peak}}$.

Deriving the 3-Point Parabolic Estimator

We sample three discrete points around the peak:

  • $y_0 = R[k_{\text{peak}}]$ (The discrete maximum)
  • $y_{-1} = R[k_{\text{peak}} - 1]$ (Left neighbor)
  • $y_{+1} = R[k_{\text{peak}} + 1]$ (Right neighbor)

Fit a local continuous quadratic polynomial $y(x) = a x^2 + b x + c$, setting $x = 0$ at $k_{\text{peak}}$:

$$y(0) = c = y_0$$ $$y(-1) = a - b + y_0 = y_{-1}$$ $$y(+1) = a + b + y_0 = y_{+1}$$

Subtracting and adding the equations solves directly for coefficients $a$ and $b$:

$$b = \frac{y_{+1} - y_{-1}}{2}, \qquad a = \frac{y_{+1} - 2y_0 + y_{-1}}{2}$$

The continuous peak occurs where the derivative is zero: $y'(x) = 2ax + b = 0$:

$$\delta = -\frac{b}{2a} = \frac{y_{-1} - y_{+1}}{2(y_{-1} - 2y_0 + y_{+1})}$$
Achieving 5-Meter Accuracy from a 2 MSPS Dongle

The true continuous time difference of arrival is:

$$\Delta t_{\text{true}} = (k_{\text{peak}} + \delta) \cdot T_s$$

Under typical signal-to-noise ratios, parabolic fitting extracts fractional timing down to $1/25\text{th}$ to $1/50\text{th}$ of a sample:

$$\text{Position Error} \approx \frac{150\text{ meters}}{30} \approx \mathbf{5\text{ meters}}!$$

A $30 RTL-SDR sampling at only 2.0 MSPS achieves the spatial precision of a 60 MSPS high-end laboratory digitizer!

3. The Algorithm in 15 Lines of Code

import numpy as np

def gcc_phat_subsample(sig_a, sig_b, fs=2.0e6, eps=1e-6):
    # 1. Frequency domain cross-spectrum
    X = np.fft.fft(sig_a)
    Y = np.fft.fft(sig_b)
    G = X * np.conj(Y)
    
    # 2. Phase Transform (whitening magnitude to 1.0)
    R_phat = np.fft.ifft(G / (np.abs(G) + eps)).real
    
    # 3. Integer peak
    k_peak = np.argmax(R_phat)
    
    # 4. 3-point parabolic sub-sample refinement
    y_m1 = R_phat[(k_peak - 1) % len(R_phat)]
    y_0  = R_phat[k_peak]
    y_p1 = R_phat[(k_peak + 1) % len(R_phat)]
    
    delta = (y_m1 - y_p1) / (2.0 * (y_m1 - 2.0 * y_0 + y_p1))
    
    # 5. Continuous time delay
    delay_seconds = (k_peak + delta) / fs
    return delay_seconds

4. Solving the Hyperbolic System: Bancroft's Algorithm

Once you have measured range differences $r_{i, 1} = c \cdot \Delta t_{i, 1}$ across 4 or more synchronized receivers:

$$r_{i, 1} = \|\mathbf{x} - \mathbf{x}_i\| - \|\mathbf{x} - \mathbf{x}_1\|$$

In 1985, Stephen Bancroft developed a closed-form algebraic algorithm using the Minkowski spacetime Lorentz metric $M = \text{diag}(1, 1, 1, -1)$.

By treating the receiver coordinates and pseudoranges as 4-vectors in Minkowski spacetime, the non-linear hyperbolic equations collapse into a simple quadratic equation:

$$A \lambda^2 + B \lambda + C = 0$$

which is solved in constant time with zero iterative gradient steps and zero risk of local minima trapping!
