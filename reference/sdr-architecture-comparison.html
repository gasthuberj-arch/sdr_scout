SDR Architecture Reference: Comparative Tradeoffs

When receiving radio signals, an SDR pipeline converts analog electromagnetic waves into digitized baseband I/Q samples, then passes them through digital filtering, synchronization, demodulation, bit-framing, and state management. The choice of runtime architecture fundamentally dictates system throughput, latency jitter, and operational safety.

Architectural Comparison Matrix

Primary Philosophy Native SIMD DSP core + OTP actor concurrency and supervision Flowgraph of modular C++ stream blocks scheduled in thread pools Monolithic single-process or Unix pipe composition
DSP Throughput High (2–10 MSPS) with zero-copy binary passing and SIMD Maximum (20–100+ MSPS) via circular buffers and SIMD (VOLK) Maximum (20–100+ MSPS) with hand-tuned cache locality
Latency & Jitter Predictable soft realtime; risk of BEAM stall if NIF runs >1ms Extremely low buffer latency; deterministic DSP block execution Hard/near-hard realtime; lowest possible jitter for TX/PTT timing
Flow Control & Backpressure GenStage demand-driven pull backpressure prevents memory leaks Circular buffer full/empty signaling with block backpressure OS pipe buffers (`FIFO`), explicit ring buffers, or dropped packets
Fault Tolerance Supervision trees: decoder crashes self-heal without killing radio stream Single segfault or unhandled exception terminates whole flowgraph Crash terminates daemon; requires external init/systemd restart
Cluster / Networking Native OTP / :pg distribution across nodes with zero extra code Requires external ZeroMQ, TCP sinks, or MQTT glue services Requires custom socket programming or external forwarders
Protocol Dissection Elite: pattern-matching bitstrings (`<<flag::1, data::7>>`) Awkward: manual C++ bitshifts or Python bridging overhead Performant but verbose: manual bitmasks (`(b >> 3) & 0x07`)

Suitability for Amateur (HAM) Radio Modes

Ideal Fits for Elixir + Zig
  • Distributed APRS / AX.25 Digipeaters: Connecting multiple RF receivers over mesh or internet, deduplicating packets, and publishing to APRS-IS.
  • Multi-Channel FT8 / WSPR Decoders: Splitting audio-frequency bands into parallel worker processes, doing FFT in Zig and message state tracking in Elixir.
  • Telemetry & Satellite Ground Stations: Cubesat telemetry reception (e.g. NOAA APT, AX.25 Fox-1), where stateful flight tracking and web/telemetry broadcasting shine.
When to Avoid Elixir + Zig (Use Pure C/Rust or GNU Radio Instead)
  • Ultra-Wideband Sweep / Spectrum Analysis: HackRF sweeps at 20+ MSPS require gigabytes/sec of raw RAM bandwidth and direct GPU/FPGA offloading.
  • Strict Half-Duplex / Full-Duplex Transceivers (TX/RX switching): HAM PTT (Push-To-Talk) turnaround and TDMA slots (such as DMR tier II 30ms time slots) require microsecond-level phase lock that BEAM garbage collectors can disrupt if unshielded.
  • Embedded Microcontrollers: Running on microcontrollers (ESP32, STM32) without a full OS or BEAM VM.
